# 单竞品分析研究 Skill

一个用于深入研究单个竞品的 Codex Skill。它按定位、用户、技术、模型、基础五层组织研究，但把五层作为方法论而非固定报告目录；研究过程中每完成一层，就与用户讨论主要发现、关键依据和下一层计划。

研究保持证据深度，明确区分实测事实、公开资料、研究推断与未知。需要用户亲自体验时，Skill 会提供操作步骤和回传要求。研究完成后交付研究结果，不自动撰写报告或导入飞书。

本项目由个人维护，不代表任何被分析产品的官方实现。

## 适用场景

- 研究一个产品如何为特定用户和场景交付价值。
- 需要真实体验、公开资料和分析判断互相补证的产品拆解。
- 需要在研究进行中逐层讨论发现和研究取舍。
- 需要按条件深入 Workflow、单 Agent、多 Agent 或模型机制。

它不负责多竞品横向比较、正式报告写作、需求排期或飞书导入。需要 Agent 深挖时，可配合 [single-agent-analysis](https://github.com/BMBWaveforms/single-agent-analysis)。

## 研究流程

Skill 在定位、用户、技术、模型、基础各层推进。每层完成后会简要交代：

1. 本层的主要发现。
2. 支持判断的关键证据和不确定之处。
3. 下一层的研究建议及理由。

用户讨论并调整重点后再进入下一层。需要用户亲自体验时，Skill 会先说明任务、输入、观察重点和回传材料。完整证据与分析细节留在研究结果中，层间交流只讲重点。

## 安装与调用

将仓库克隆到 Codex 或兼容客户端识别的 Skills 目录，保持目录名 `single-competitor-analysis` 和内部相对路径不变。安装路径因客户端和环境而异，请以所用环境的 Skill 说明为准。

调用示例：

```text
请用 $single-competitor-analysis 研究这个产品：[产品名称和入口]。
重点是：[研究目标或场景]。每完成一层，请先告诉我主要发现、关键依据和你建议的下一步，等我讨论后再继续。
如果需要我亲自体验，请先给我具体操作步骤和需要回传的内容。
```
